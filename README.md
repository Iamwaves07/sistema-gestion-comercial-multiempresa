# Sistema de Gestión Comercial Multiempresa

Proyecto desarrollado para la asignatura de Seminario de Título.

El objetivo es crear un sistema de gestión comercial para PYMEs que permita trabajar con varias empresas dentro de una misma plataforma, manteniendo los datos separados según la empresa de cada usuario.

El sistema incluirá funciones para administrar:

- Empresas
- Usuarios y roles
- Categorías
- Productos
- Clientes
- Inventario
- Movimientos de stock

## Tecnologías

- React
- Vite
- Node.js
- Express
- PostgreSQL
- Prisma ORM
- JWT
- Git y GitHub

## Estructura del proyecto

- `backend`: API y lógica del sistema.
- `frontend`: interfaz de usuario.
- `docs`: documentación y diagramas.
